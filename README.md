# H3商品

用于 ComfyUI 的商品视频制作插件：用首尾帧安排安装、使用及成品展示步骤，连续步骤可读取上一段实际视频的最后一帧。

## 下载与安装

**[下载安装包](https://github.com/qqweiyijianyi/H3-Product/releases)**

1. 在 Releases 下载文件名含 `Windows-x64` 的 ZIP，解压得到 `ComfyUI-H3-Product`。
2. 将文件夹放入 ComfyUI 的 `custom_nodes`。更新时先关闭 ComfyUI，把旧的同名目录移出 custom_nodes 后再放入新版，避免旧文件残留。
3. 重启 ComfyUI 并刷新浏览器，搜索 **H3商品** 添加节点。
4. 外接你已有的 H3 MODEL（可带 LoRA）、CLIP、视频 VAE、音频 VAE。第一段设置首帧、目标尾帧和动作提示词；下一段可选择“上一段实际视频末帧”。

本仓库只提供发布说明和下载入口，`git clone` 不会获得可运行的插件；请下载 Release 附件。

## 运行条件

- 当前发布包：**Windows x64，已验证 Python 3.13**。未验证 Linux、macOS、ARM 或其他 Python 版本，请勿视为通用安装包。
- 使用支持 H3 及 ComfyUI V3 节点接口的现有 ComfyUI 环境。本次前端检查使用 1.57.4。
- 沿用现有 H3 模型和依赖；安装包不含模型。基础 Python 依赖列于包内 requirements.txt。
- API 润色是可选功能，需要自行配置服务；服务费用按供应商规则收取，不影响本地基础制作。

## 当前功能

- 单页步骤编排、首尾帧、实际末帧续接。
- 脚本全部/当前段/追加导入，图片、音频、宫格素材。
- 参考视频与 Solar 白模处理（相关外部插件和模型另行准备）。
- 视频历史版本选择、合并导出、像素超分、项目保存恢复。
- 选中文字 API 润色。

v0.2.0 已移除原包内的 Motion Context、时间线 GPL 运行时及其依赖的原二采、多帧上下文、整轨锁音功能。没有修脸功能。
